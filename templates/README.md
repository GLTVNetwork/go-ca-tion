# Destination pages — keep it simple

Copy `travel/adena-mansion-gardens/index.html` into `travel/<destination-slug>/index.html`. All destination folders use the shared `travel/destination.css`; no build tools or JavaScript are required.

For each destination replace the title, description, canonical URL, name/location, real hero image and alt text, history and source links, visit notes/photos, return ideas, nearby stop, address, and verification date. Keep the same section anchors and relative navigation paths. Add a card to `pages/travel.html` and the destination URL to `sitemap.xml`.

Keep personal experiences grounded in Mike and Sherry's notes. Never copy Adena's visit story into another destination. Use images already owned/approved for the site, with accurate captions. If visit notes are missing, use the short transparent pending message or omit the unverified detail.

Only add videos after verifying the exact URL, destination, title, and Gocation Life channel. Use a titled, lazy-loaded iframe with class `video` and a `https://www.youtube-nocookie.com/embed/VIDEO_ID` source plus allowfullscreen. Shorts use class `video short`. Add a normal link to the verified watch/Shorts URL beneath it. Do not put guessed IDs or empty players on the public page.

Nearby vintage/antique stops are optional. Include them only with a current source link, and distinguish suggestions from places actually visited. Link to official hours rather than duplicating details that change. Remove optional sections and their jump links when unused.

Review on a phone and desktop before publishing. This Adena version is a review draft: both video URLs were supplied by the user and verified through YouTube oEmbed; additional personal visit notes can follow review.
