What the packet begins

Understand. Talk. Agree—or file.

01

Receive a Case Number

After you request an ICCS packet, your unique Case Number is sent separately. It remains active for one year from the date it is issued.

02

Start with the Notice

Each person explains how they see the matter and makes one final effort to resolve it.

03

Agree or File

Return the Agreement if Common Sense prevails—or submit the Official ICCS Filing for a ruling.
